# Hello Halo Desserts

Hello Halo is a static multi-page website for a Filipino dessert shop in Iloilo City. The project is designed to showcase a dessert brand with a warm, colorful visual identity, menu highlights, and local business information.

## Overview

This website presents Hello Halo as a modern Filipino dessert shop with a strong focus on halo-halo, ube-inspired treats, and refreshing dessert options. The content is organized into a simple browsing experience for customers who want to learn about the brand, browse menu items, view gallery highlights, and contact the shop.

## Pages

- Home
- About Us
- Services menu
- Gallery
- Contact Us

## Features

- Responsive multi-page layout
- Mobile-friendly sidebar menu navigation
- Hero banner and dessert promotion sections
- Highlight cards for featured items and store offerings
- Social links, branch information, and contact details
- A clean static front-end style suitable for a small food business website

## How to View

Open `Hello Halo/home.html` in a web browser. The navigation links connect the other pages, and the form is for demonstration only.

## Project Structure

- `Hello Halo/` contains the HTML pages.
- `style/` contains the CSS files for each page and shared design styles.
- `img/` contains image assets used across the website.
- `script.js` controls the shared sidebar menu behavior.

## Design Notes

The website uses a vibrant color palette inspired by desserts and Filipino flavors, including warm cream tones, purple accents, and a clean card-based layout. The typography and spacing are designed to feel approachable and cheerful, matching the brand's casual dessert-shop identity.

## Future Improvements

This project can be expanded with:

- an updated menu pricing section,
- scroll animations,
- a stronger gallery layout,
- online ordering or reservation interactions,
