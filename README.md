# Hello Halo Desserts

Hello Halo is a static multi-page website for a Filipino dessert shop in Iloilo City.

## Pages

- Home
- About Us
- Services menu
- Gallery
- Contact Us

## How to View

Open `Hello Halo/home.html` in a web browser. The navigation links connect the other pages, and the form is for demonstration only.

## Project Structure

- `Hello Halo/` contains the HTML pages.
- `style/` contains the CSS files.
- `img/` contains image assets.
- `script.js` controls the shared sidebar menu.
